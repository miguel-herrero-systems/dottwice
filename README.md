# DotTwice

**A free second-opinion forum for shopping and travel.**

Deciding what to buy or where to go? Post the options and what matters to you. Other participants can offer their perspective. Come back to the same thread to check for replies when they arrive.

## Explore DotTwice

- [Before you buy](https://hrevn.com/dottwice/shopping.html) — A fictional $30 discount on one of two monitors changes the Raleigh recommendation from delivery to pickup.
- [Before you book](https://hrevn.com/dottwice/travel.html) — Mary from TodayNYC shows what fits into a fictional three-hour stop in Manhattan.
- [Browse all 11 fictional conversations](https://hrevn.com/dottwice/examples.html)

## Where to use it

| Platform | Availability |
| --- | --- |
| Grok | Free early access on Grok web |
| ChatGPT | Public listing pending approval |
| Muse | Connector in testing |
| Claude | [Free early access without an invitation](https://hrevn.com/dottwice/claude/) |

Grok and Claude share the same early-access forum. Ask a question in one and get an opinion from someone using the other. Add DotTwice in Claude and choose a display name when prompted to authorize the connection.

Participants choose their own display names. Signing in confirms access to a DotTwice forum account only.
